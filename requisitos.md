# Requisitos - Helix Health

## Visao Geral

Sistema hospitalar completo para gerenciamento de pacientes, profissionais, atendimentos, prontuarios, exames, internacoes, estoque/farmacia, financeiro e pronto socorro.

## Usuarios e Acessos

- Login para medicos.
- Login para almoxarifado.
- Login para recepcao.
- Login para administrador.
- Login para enfermeiro.
- Login para paciente.
- Login para financeiro.
- Login para farmacia.
- Dashboard administrativo com indicadores gerais do hospital.
- Visualizacao rapida de proximos agendamentos, triagens urgentes, exames pendentes e ocupacao de leitos.

## Pacientes

- Cadastro completo de pacientes.
- Registro de CPF.
- Registro de telefone.
- Registro de endereco.
- Registro de convenio.
- Registro de contato de emergencia.
- Historico de atendimentos do paciente.
- Tela de detalhes do paciente com dados pessoais e historico completo.
- Visualizacao de agendamentos, atendimentos, prontuarios, exames, prescricoes, internacoes e triagens por paciente.

## Profissionais

- Cadastro de profissionais.
- Cadastro de medicos.
- Cadastro de enfermeiros.
- Cadastro de recepcionistas.
- Cadastro de fichario.
- Cadastro de especialidades.
- Controle de pre-consulta.
- Controle de pos-consulta.
- Controle de horas disponiveis.

## Agendamentos

- Marcar consulta.
- Cancelar consulta.
- Remarcar consulta.

- Filtrar agendamentos por medico.
- Filtrar agendamentos por paciente.
- Filtrar agendamentos por data.
- Relacionar agendamento com prontuario.

## Farmacia e Estoque

- Entrada de estoque.
- Saida de estoque.
- Controle de validade.
- Controle de estoque minimo.

- Filtros de medicamentos por nome, fornecedor e status.
- Controle de almoxarifado.
- Cadastro de materiais hospitalares.
- Listagem de materiais hospitalares.
- Edicao e exclusao de materiais hospitalares.
- Filtros de materiais por nome, categoria, fornecedor e status.
